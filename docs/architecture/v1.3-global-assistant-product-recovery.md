# Global Assistant Product Recovery

## Purpose

The Global Assistant accepts open English and Italian SOC language while
keeping execution closed. The former whole-sentence embedding router and its
regex-based slot recovery are replaced by compositional interpretation:

1. local Stanza language identification and Universal Dependencies parsing;
2. local multilingual E5 classification of atomic action, entity, temporal,
   day-part and open-set primitives;
3. authoritative resolution of host and detection-rule candidates from the
   RBAC-scoped SQL data;
4. a closed `SemanticQueryAST` containing operation, source, target,
   aggregation, distinctness, positive and negative filters, dimensions,
   ordering, limit, time windows, comparison windows and typed conversation
   references;
5. validation against the closed analytics registry before SQLAlchemy or
   reference execution;
6. typed analytical proof units, one Qwen generation at most, V3.2 semantic
   proof, and atomic model-response or deterministic-fallback publication.

Natural language never supplies table names, columns, joins, functions,
operators or SQL fragments. The interpreter contains no regular-expression
NLU, sentence-template router, acceptance-query branch or generated SQL path.
Compact concept prototypes describe atomic semantic classes; they are not
question exemplars.

## Authority Hierarchy

- SQL records remain `OPERATIONAL_AUTHORITATIVE` and are RBAC-scoped before
  selection, grouping or aggregation.
- Registered deterministic results remain `ANALYTICAL_DERIVATION`.
- Platform-recorded correlations remain operational relationships.
- Deterministically constructed cross-incident relationships remain
  analytical derivations.
- Qdrant remains semantic discovery/support only; candidate IDs are rehydrated
  and authorized through SQL before use.
- MITRE definitions come only from the bounded local reference catalog.
- Model-authored references and prior generated prose are never authority.

## Local Runtime

The semantic layer is non-generative and offline at request time:

- Stanza 1.11 EN/IT `tokenize,pos,lemma,depparse` no-charlm packages;
- `intfloat/multilingual-e5-small` on CPU;
- dateparser and python-dateutil for structured temporal values.

The API starts an asynchronous prewarm for both Stanza language pipelines and
the E5 concept vectors. Runtime loaders disable model downloads. Provision the
assets explicitly with `scripts/provision_semantic_nlu_models.py`; paths may be
overridden with `AI_SOC_SEMANTIC_NLU_MODEL_DIR` and
`AI_SOC_SEMANTIC_NLU_EMBEDDING_MODEL`.

## Closed Analytics Algebra

The registered execution surface supports bounded list, count, count-distinct,
top/frequency, distribution, daily trend, period comparison, host comparison,
recorded relationship lookup, semantic candidate discovery and MITRE reference
lookup. Filters are typed and support equality, set membership and their
negative forms. Temporal windows are half-open UTC intervals resolved in
`Europe/Zurich`, including rolling, calendar, day-part, boundary, time-only and
absolute range expressions.

Typed conversation state stores the preceding plan fingerprint, operation,
entity, filters, dimensions, time/comparison windows and authorized result IDs.
Follow-ups extend that state; generated prose is not read back as evidence.

## Supported Boundaries

The Global scope covers authoritative incident/case counts and lists, hosts,
detection rules, recorded status/risk, MITRE distributions/reference,
case-SLA state, recorded correlations, semantic similarity candidates and
incident-scoped advisory requests. A request without enough authoritative
scope for a playbook or remediation answer is rejected or narrowly clarified;
the model is not allowed to fill the gap from general cybersecurity knowledge.
Platform facts execute only where a typed authoritative provider exists.

Security invariants remain unchanged: one Qwen call maximum, no retry, repair,
critic, rewrite, model switch or cloud inference, and deterministic fail-closed
publication after any schema or semantic-proof failure.
